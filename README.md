# Availability: Group Intake Access

## Summary

This availability condition plugin works with the Group Manager (localgroupmanager) plugin to enforce time-based access control for course activities.

## Description

This availability condition plugin works with the Group Manager (localgroupmanager) plugin to enforce time-based access control for course activities.

## Requirements

- Moodle 4.0 or higher
- localgroupmanager plugin installed and configured

## Installation

- Install localgroupmanager first
- Install this plugin to availability/condition/groupmanager/
- Enable the condition in Site Administration → Plugins → Availability restrictions
- Apply the condition to activities that should respect group dates
